Home page

Welcome to the Spellforce Songmap. This application is dedicated to the wonderful soundtrack of Spellforce 1.

Discover interactively on what maps and in what locations which tracks are played.

The song system of Spellforce

Each map of Spellforce has two tracks by default. One, which is played as an Opener when entering the map. Once the Opener has finished a second track is looped indefinitely. A few maps posses no Opener in which case the Loop is immediately played.

Following the same principle within certain locations tracks are played once the avatar moves onto them. For example within the city of Greyfell the track sharrowdale.mp3 is played (once).

A number of songs within the soundtrack however are played only on these occasions:

  • the player is in the menu

  • the player’s army is enganged in combat

  • the avatar dies/moves to a different map

The information on this site is based on an analysis of the file SndTracks.lua within the game’s script files published by THQ Nordic.
